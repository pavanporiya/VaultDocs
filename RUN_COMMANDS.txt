============================================================================
 VAULTDOCS — HOW TO RUN (COPY-PASTE GUIDE)
 Last updated: 2026-09-24
============================================================================
 Is guide me har command aise likha hai ki aap seedha copy-paste karke
 project chala sako. Bas steps order me follow karo.

 REQUIREMENTS (one-time install):
   1. Python 3.11+          -> https://www.python.org/downloads/
   2. uv (Python manager)   -> install command niche STEP 1 me
   3. Node.js 18+           -> https://nodejs.org
   4. Docker Desktop        -> https://www.docker.com/products/docker-desktop
                               (database ke liye, easiest option)

 Apna setup check karne ke liye (PowerShell / Terminal):
   python --version
   node --version
   npm --version
   docker --version

============================================================================
 STEP 0 — CODE LAO
============================================================================

 Pehli baar (fresh clone):

     git clone https://github.com/pavanporiya/VaultDocs.git
     cd VaultDocs

 Agar code pehle se hai, bas us folder me jao:

     cd path/to/VaultDocs

============================================================================
 STEP 1 — uv INSTALL (agar pehle se nahi hai)
============================================================================

 Windows (PowerShell):

     powershell -c "irm https://astral.sh/uv/install.ps1 | iex"

 macOS / Linux:

     curl -LsSf https://astral.sh/uv/install.sh | sh

 Check:

     uv --version

 NOTE: Install ke baad terminal ek baar band karke dobara kholna pad sakta hai.

============================================================================
 STEP 2 — DATABASE START (PostgreSQL)
============================================================================

 OPTION A (RECOMMENDED): Docker se database ek line me up

     docker run -d --name vaultdocs-db -e POSTGRES_DB=VaultDocs -e POSTGRES_USER=VaultDocs_user -e POSTGRES_PASSWORD=change-me-in-production -p 5433:5432 postgres:16-alpine

 Database band/stop karne ke liye (data delete nahi hoga):

     docker stop vaultdocs-db

 Dobara start karne ke liye:

     docker start vaultdocs-db

 OPTION B: docker compose (repo root se, sirf database service):

     docker compose up -d db

 OPTION C: Agar PostgreSQL locally installed hai:
     - .env file me apne database ki details bhar do (STEP 3 dekho)
     - Database "VaultDocs" exist karna chahiye

============================================================================
 STEP 3 — .env FILE (agar pehle se hai to SKIP karo)
============================================================================

 Project root me .env file banao aur ye content daalo:

     # --- Database ---
     DATABASE_HOST=localhost
     DATABASE_PORT=5433
     DATABASE_NAME=VaultDocs
     DATABASE_USER=VaultDocs_user
     DATABASE_PASSWORD=change-me-in-production

     # --- App ---
     APP_ENV=development
     DEBUG=true
     SECRET_KEY=change-this-to-any-random-secret-string

 NOTE:
   - .env kabhi git me commit MAT karna.
   - STEP 2 Option A wale docker command ke credentials upar wale se
     exactly match karte hain, isliye ye combo seedha kaam karega.

============================================================================
 STEP 4 — BACKEND SETUP (one-time dependencies install)
============================================================================

 Project root se:

     uv sync

 Ye saare Python packages install kar dega (virtualenv khud ban jayega).

============================================================================
 STEP 5 — DATABASE TABLES BANAO (migrations)
============================================================================

 Project root se:

     uv run alembic upgrade head

 Ye command idempotent hai — jitni baar marzi chala sako,
 already-applied migrations dobara nahi chalenge.

============================================================================
 STEP 6 — BACKEND START
============================================================================

 Project root se:

     uv run uvicorn vaultdocs.main:app --port 8000

 Backend chalu hone ke baad ye check karo (naya terminal kholo):

     curl http://localhost:8000/v1/health

 Expected output me "healthy" aur "database":"connected" dikhna chahiye.

 API docs browser me: http://localhost:8000/docs

============================================================================
 STEP 7 — FRONTEND START (naya terminal kholo)
============================================================================

     cd frontend
     npm install
     npm run dev

 Terminal me Vite ek URL print karega, normally:

     Local: http://localhost:3000/

 Wahi URL browser me kholo. Bas — app chal rahi hai!
 Register karke login karo aur use karo.

 NOTE:
   - Agar port 3000 busy hai to Vite khud 3001/3002 pe chala jayega —
     jo URL terminal me print ho, WOHI use karo.
   - Frontend ka /v1 proxy backend (localhost:8000) pe automatically
     jaata hai, kuch karne ki zarurat nahi.

============================================================================
 EK LINE ME (har naye session ke liye)
============================================================================

 Terminal 1 (database, agar band hai):
     docker start vaultdocs-db

 Terminal 2 (backend):
     uv run uvicorn vaultdocs.main:app --port 8000

 Terminal 3 (frontend):
     cd frontend && npm run dev

 Browser: http://localhost:3000

============================================================================
 TROUBLESHOOTING (common problems)
============================================================================

 1) "relation users does not exist" / registration pe 500 error
    -> Migrations nahi chale. Ye chalao:
       uv run alembic upgrade head

 2) Port 8000 already in use (WinError 10048)
    -> Purana backend chal raha hai. Kill karo:
       Windows:  netstat -ano | findstr :8000
                 taskkill /PID <upar-wala-pid> /F
       Mac/Linux: kill $(lsof -t -i:8000)

 3) "database connected" nahi aa raha / connection refused
    -> Database container chal raha hai? Check:
       docker ps
    -> Nahi hai to STEP 2 wala command dobara chalao.
    -> .env ke DATABASE_* values docker wale credentials se match karo.

 4) Frontend pe API errors (network/CORS jaisa kuch)
    -> Backend port 8000 pe chal raha hai? Health check karo:
       curl http://localhost:8000/v1/health
    -> Backend restart karo.

 5) Login/Register me "invalid email" aa raha hai
    -> Email proper domain wala hona chahiye, e.g. test@example.com
       (.test jaise special-use domains backend reject karta hai).

 6) npm install fail ho raha hai
    -> Node version check karo (18+ chahiye): node --version
    -> Phir ye try karo:
       cd frontend
       rmdir /s /q node_modules        (Windows)
       rm -rf node_modules             (Mac/Linux)
       del package-lock.json           (Windows)
       rm package-lock.json            (Mac/Linux)
       npm install

 7) "uv: command not found"
    -> STEP 1 dobara karo aur terminal restart karo.

 8) Files upload nahi ho rahi
    -> Max size 10MB hai (backend limit). Chhoti file se test karo.

============================================================================
 OPTIONAL — FULL DOCKER MODE (backend + database dono containers me)
============================================================================

     docker compose up -d --build
     uv run alembic upgrade head
     cd frontend && npm run dev

 Logs dekhne ke liye:
     docker compose logs -f app

 Sab band karne ke liye:
     docker compose down

 WARNING — ye database ka POORA DATA delete kar deta hai:
     docker compose down -v

============================================================================
 QUALITY CHECKS (developers ke liye, optional)
============================================================================

     uv run pytest
     uv run ruff check .
     uv run ruff format --check .
     uv run mypy backend/src
     uv run alembic check

 Frontend:

     cd frontend
     npm run lint
     npm run build

 Full E2E (backend + frontend chalu hone ke baad):

     node scripts/e2e-api-verify.mjs
     node scripts/e2e-browser-qa.mjs http://localhost:3000
